# Proofs of the laws (LAWS.bend, laws/)

Every law of laws/ is proven in `proof/<area>/<law>.bend`: `bend PROOF.bend` prints ALL PROOFS CHECK when no law is open or false; that is the gate. `bend PROOF.bend --verdict` (the kernel, with a fuel budget per def) is optional.

One file per law; lemmas in `base.bend`. NEVER `@unsafe`, `?` holes, or edits to LAWS.bend, laws/ or LAWS.lock. The proofs compute the laws on `build/site.bend` (generated, gitignored): write it from a fresh `vp build` first (`npm run laws`).

## Cost under `--verdict`

The kernel gives each proof a fixed budget ("out of fuel" past it; not a false law). The site is about 1.1 MB, so every pass must stay cheap:

- Read a page one character at a time; match `Chr{n}` literals, one state per handler (`Lx.step`, `Page.char`); no lookahead patterns with a fallback on a computed string.
- No `Nat` or `U32` counter per character: count with strings (`Ratio.twenty`, `Ratio.le`).
- `+` on a large value only where a function runs once (`Text.end`, `Outline.of`): `+` normalizes the value on every call.
- Keep only what a law reads: the lexer drops the attributes it has no `Key` for, and the raw text of script and style (`Raw.keep`).

- No deep `Chr{n}` literal pattern after another literal arm with a fallback (`SCon{a, SCon{b, SCon{Chr{45}, ..}}}` after `SCon{Chr{45}, t}`): `--verdict` never finished checking one; test characters with a helper (`Dash.is`).
- No string in a state the pass keeps per character (`+` copies it each step): `home_text`'s raw-text states hold an enum (`Raw`), not the element's name; with the name, it ran out. The lexer's raw-text buffer is dup'ed only at a "<" (`Raw.lt`).
- One def's check has one budget: 12 pages' heading and lang checks fit, 18 do not. `Both.all` joins chunks of 6 (`All.split`); a chunk that runs out after pages are added splits again.
- A claim across pages (titles distinct, `metadata`) cannot be computed on all pages in one def: 10 pages' `Snip.all` run out. `proof/meta/pages.bend` proves, per chunk of 3 pages (`Pg.a`–`Pg.f`), that the pages read whole give what reading only each page's start gives (`fall.bend`), and `metadata.bend` computes the claim on the starts. Two laws over the same pages share one lexing per page (`Two.toks` takes the tokens as one `+` argument): `canonical` and `metadata` cost about as much as one.
- A lemma's type must match the goal as written when it holds a costly term: `{Canon.all(Pg.a()) == True}` given where `{Canon.all(Out.take(3n, pages)) == True}` is expected ran out of fuel (the kernel computes both to compare). `proof/meta/` writes the chunks one way (`B.Pg.a()` .. `B.Pg.f()`) and rewrites with `B.Pg.split`.

R10 (`laws/links/`, `proof/links/`) taught these, measured with a copy of Bend's `bendtt.lean` whose `Ctx.need` prints the fuel a check used and `Book.check_from` each def's name, built with FUEL raised to 4000M so an overrun shows its size (`bend` runs the kernel named by `$BENDTT`); the budget is 400M:

- The kernel has no native numbers. A `Char` is a 32-bit `Word`: comparing two (`U32.cmp`, `Char.is_eq`, Base `String.eq`, `Ord.go`) costs about 3,500 fuel per character, and Base `Char.to_lower` (`U32.mul`) far more (it made each URL cost 1.4M: `Pre.low` is a literal match). A literal `case Chr{n}` match is a walk down the 32 bits, about 800. `links/serve.bend` converts keys once to 7-bit `Cp` characters (`Cp.of`, a literal match) and compares those (`Key.go`, a few hundred per character); `Cp.back` undoes `Cp.of`.
- `+x` normalizes `x` each time it is bound, walking it whole even when it is already normal: a `+` accumulator in a loop over characters is quadratic (`Ss.go`, `Md.go` keep their state in one record whose fields each arm uses once). A value used in two places is copied whole: `Key.tri` compares a key with a path and gives the path back, so that `Df` never copies a path, and a path's characters are converted (lazily) only as far as they are compared.
- A def cannot call a def defined after it, nor match a local binder: a loop that must branch on a computed value is a fuel-bounded state machine whose step helpers come first (`Df.loop`, `Mg.loop`, `Tr.loop`).
- Lexing a page costs about 1,000 fuel per character (all.html, 127 KB: 103M). R10 on all.html in one def took 418M, so `Html.all` checks each page in two halves of its start tags (`R.Tags.half`), each lexing the page again. With redirect-first resolution (function routes, then exact `_redirects` sources, then files; `_headers`, `_redirects`, `_routes.json` not served; a wildcard path rule fails all), measured on the whole `--verdict` run before the single parse below: all.html's halves take 280M and 287M (`Ev.c1`, `Od.c1`), `Ev.c3`/`Od.c3` 232M, `Text.c1` (llms-full.txt and the last files) 238M; all under 400M. The overruns on that run were outside links (`Two.ca` 431M, `Two.cd` 413M, law `sitemap` 426M).
- `Links.ok` reads `_redirects` once (`V.Rd.of`: one pass over its lines gives the exact rules and the wildcard flag, `LRd`) and passes the rules to `Served.with` and `Frag.all`; before, it parsed the file twice per call and again for each reference with a fragment to another page (`Pg.of`).
